# SSC AI VedIQ Learning Platform

An AI-powered learning platform/companion for SSC students.

## First vertical slice

Class 10 Science  
Chemical Reactions and Equations  
Combination Reactions

The first release will allow a student to:

1. Open a concept lesson
2. Read an explanation
3. Take a quiz
4. Receive feedback
5. Save progress
6. Ask questions through an AI tutor

## Planned architecture

- React and TypeScript frontend
- Java and Spring Boot backend
- PostgreSQL database
- AI tutor using retrieval-augmented generation
- Docker-based local development
- AWS deployment
