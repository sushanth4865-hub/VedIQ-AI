# First Vertical Slice Requirements

## User

Class 10 SSC student

## Learning flow

The student can:

1. Open the Combination Reactions concept
2. Read the concept explanation
3. View an example chemical equation
4. Take a five-question quiz
5. Submit answers
6. View the score and explanations
7. Save concept progress
8. Ask the AI tutor questions about the concept

## Initial scope

- One board
- One grade
- One subject
- One chapter
- One concept
- One student role
- English content first
- Local development first

## Out of scope for the first release

- Payments
- Parent dashboard
- Teacher dashboard
- Videos
- Telugu content
- Microservices
- Kafka
- Kubernetes
- Production deployment
